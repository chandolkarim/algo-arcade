# REBOUND 25/200 · 2번 기계

일봉으로 큰 추세 안의 단기 되돌림을 관찰하는 연구용 알고리즘입니다. Python 표준 라이브러리만 사용합니다. 계정·인증키·주문 API는 없습니다.

## 아이디어 출처

BNF의 매매로 알려진 25일 이동평균선 괴리율을 활용한 단기 역추세 매매에서 착안했습니다. 정찬민이 200일선 위 롱·아래 숏 방향 필터를 제안했고, 이 프로젝트에서 ATR 진입/손절과 시간 청산을 구체화했습니다. BNF 본인의 전략을 그대로 복제했다는 뜻이 아니며, 여기의 수치는 모두 이 구현의 결과입니다.

- [BNF 관련 제3자 해설](https://toushi-strategy.com/backtest/bnl_ma_kairi1/) — 본인 공식 매뉴얼이나 인증 자료 아님
- [Fidelity ATR 설명](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)
- [Binance 일봉](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Kline-Candlestick-Data), [펀딩 이력](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Get-Funding-Rate-History)
- [Yahoo Finance](https://finance.yahoo.com/), [NAVER 금융](https://finance.naver.com/)

## 실행

저장소 루트에서 Python 3.9 이상으로 실행합니다.

```bash
python3 rebound/update.py
python3 -m unittest discover -s rebound -p 'test_*.py' -v
```

첫 명령은 공개 시세를 수집하고 백테스트·모의 장부·사이트 결과를 갱신합니다. `--offline`은 이미 저장한 원본 캐시로 백테스트만 재계산하며 모의 장부를 진행시키지 않습니다. 캐시 없는 첫 실행에는 인터넷이 필요합니다. 시세 또는 모의 장부 오류가 하나라도 있으면 종료 코드 1이며 성공한 종목 결과는 저장됩니다.

`data/rebound.json`은 전체 결과이며 `data/rebound-data.js`는 같은 내용을 JavaScript 변수로 감쌉니다. HTML을 `file://`로 열어도 이 파일을 읽을 수 있습니다. JSON을 HTML 문자열로 삽입하지 않으며, 화면 값은 DOM textContent로 표시합니다.

이 버전은 수동 갱신입니다. 일정 실행이나 공개 배포는 활성화하지 않았습니다. 예약 실행을 연결할 때에는 매 실행 후 `rebound/paper/`를 영속 저장하고 중복 실행을 막아야 합니다. 출력·장부 없이 매일 새 임시 환경을 만들면 모의투자를 이어갈 수 없습니다.

## 정확한 규칙 · v1.0.0

기호 C=확정 종가, F=SMA25, S=SMA200, A=Wilder ATR14.

- 롱 후보: `C > S + A` 그리고 `C <= F - 2A`.
- 숏 후보: `C < S - A` 그리고 `C >= F + 2A`.
- ±1 ATR 경계값은 대기. 최소 200개 과거 봉이 있어야 다음 봉에서 진입 가능.
- 다음 봉 시가가 여전히 200일선 필터 바깥이고 25일선에 도달하지 않은 경우에만 진입. 재확인은 전날 지표와 다음 시가로 한다. 다음 날 종가/ATR은 진입 결정에 사용하지 않는다.
- 진입가격은 시가에 불리한 슬리피지를 적용한 값. 손절은 진입가 ± 신호일 ATR의 2배로 고정.
- 매일 시가: 기존 포지션의 배당·차입료·시가 펀딩 → 갭 손절 → 전날 예약 청산 → 포지션이 없으면 신규 진입.
- 장중: 고가/저가가 손절선에 닿으면 손절. 진입일 손절도 가능.
- 종가: 200일선 반대편 이탈 → 25일선 복귀 → 10개 봉 보유 순으로 청산 이유를 정하고 다음 시가에 청산. 진입일을 첫 번째 봉으로 센다. 중복 사유는 체결 시점을 바꾸지 않는다.
- 같은 날 청산 후 재진입하지 않는다. 다음 봉부터 새 신호를 평가한다. 물타기·추가 진입 없음.
- 비교군은 200일선 진입 제한과 200일선 이탈 청산을 모두 제거한다. 25일선·ATR·손절·시간 청산·기간·비용은 같다.

## 자금·비용

종목별 독립 계좌로 USD/USDT 10,000 또는 KRW 1,000만에서 시작합니다. 서로 자금 이동이나 수익률 합산을 하지 않습니다. 거래당 계획 손실은 해당 계좌의 0.5%, 진입 시 명목금액은 계좌 자산의 100% 이내입니다. 수수료와 손절 슬리피지를 예상 위험에 포함해 수량을 정합니다. 갭·차입료·펀딩 등으로 실제 손실은 계획을 초과할 수 있습니다. 소수 수량을 허용하며 실제 거래소의 최소 수량, 틱 크기, 공매도 가능 여부, 증거금·청산 규칙은 재현하지 않습니다.

- 편도 수수료: 코인 0.05%, 주식 0.10% 가정.
- 편도 슬리피지: 0.05%를 항상 불리한 방향에 적용.
- 주식 숏 차입료: 연 5% 가정, 전일 종가와 달력상 경과 일수로 계산. 실제 과거 대차료나 리콜을 반영한 성과가 아님.
- 배당: ex-date의 전일 보유 수량에 롱 수취/숏 지급을 반영. 세금 제외.
- 선물: Binance 실제 펀딩률·mark 가격. 오래된 mark 가격이 비면 해당 UTC 일봉 시가를 대용하며 원본의 `mark_proxy`에 표시.
- UTC 00시 부근 펀딩은 시가 직전 보유 포지션에 반영. 당일 신규 진입 포지션에는 부과하지 않음. 당일 손절 시각은 일봉만으로 알 수 없으므로 이후 펀딩 지출은 모두 반영하고 수취는 제외하는 보수적인 근사.
- 펀딩이 하루 통째로 없는 경우 성공으로 처리하지 않음. 실제 펀딩 간격의 모든 누락을 보장해 검출하지는 못함.

## 데이터와 기간

기본 예시 종목은 BTCUSDT·ETHUSDT 선물, AAPL·SPY·삼성전자·SK하이닉스입니다. 고정된 소수 종목이라 생존자·선정 편향이 있으며 전체 시장을 대표하지 않습니다.

코인은 UTC 일봉 종료 시각을 확인합니다. 주식은 거래소 현지 날짜보다 앞선 일봉만 반영하므로 당일 장 마감 후에도 다음 현지 날짜까지 기다립니다. 주식 OHLC는 Yahoo의 분할 반영 가격, 배당은 제공된 기업행사를 사용합니다. 제공자 자체 정정이나 조정 방식에 대한 독립적인 원장 검증은 하지 않았습니다.

한국 주식의 누락 또는 저가/고가 범위를 벗어난 OHLC는 NAVER의 실제 일봉으로 보완합니다. 주변 최소 2일 종가가 두 제공자에서 1% 이내인지 확인하고, 보완 날짜와 개별 봉 출처를 기록합니다. 검증 불가 시 해당 종목을 실패로 표시합니다. 숫자를 보간하거나 이전 종가로 채우지 않습니다.

2022년부터 전체 백테스트, 2025년부터 별도 초기 자금으로 최근 구간을 계산합니다. 최근 구간은 별도의 탐색적 확인이며 완전히 미관측인 미래 검증이 아닙니다. 파라미터 탐색으로 좋은 설정만 골라 내지 않았습니다.

계좌 수익률과 최대 낙폭에는 마지막 미청산 포지션의 종가 평가손익을 포함합니다. 최대 낙폭은 일봉 종가 계좌 기준으로 장중 낙폭보다 작을 수 있습니다. 승률과 방향별 순손익은 청산 거래만 집계합니다. 거래가 0건이면 승률은 null/표본 없음이며 0%로 오인하지 않습니다. 종료일에 포지션을 강제 청산하지 않습니다.

## 등록 이후 모의 기록

첫 성공 실행에 등록 시각과 마지막 확정 봉을 저장합니다. 등록 당일에 이미 지나간 시가로 소급 진입하지 않고 **등록 다음 현지 날짜부터** 신규 진입을 허용합니다. 이후 실행은 저장된 마지막 날짜보다 새로운 확정 봉만 처리합니다. 여러 날 쉬었다 실행하면 그 사이 봉을 순서대로 처리하고 실제 관측 시각을 함께 남깁니다. 이는 일봉 기반 모의 체결이며 당시 실시간으로 주문이 나갔다는 뜻이 아닙니다.

같은 데이터를 반복 실행해도 거래를 중복 기록하지 않습니다. 규칙이 바뀌거나 과거 OHLC·지표가 정정되어 기존 마지막 관측과 달라지면 모의 장부를 보존하고 오류를 표시합니다. 분할 등 기업행사는 검토·재기준화한 뒤 새 버전 장부로 이어가야 합니다. 기존 장부를 지워 성과를 다시 시작하면 안 됩니다.

## 검증 범위

단위 테스트는 SMA/ATR 수치, 미래 데이터 비참조, 롱/숏 경계, 다음 시가 체결, 손절 고정, 갭 손절, 당일 손절, 10개 봉 계산, 필터 제거 비교, 수량 제한, 배당·차입·펀딩 부호, 중복 실행, 등록 전 소급 진입 방지, 데이터 정정·규칙 변경 시 장부 보존을 확인합니다. 테스트의 합성 가격은 실험용이며 공개 결과 파일에 넣지 않습니다.
